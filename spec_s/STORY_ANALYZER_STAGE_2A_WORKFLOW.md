**Версия:** 1.0 (июнь 2026)

**Связанные документы:** [STORY_ANALYZER_STAGE_2A.md](STORY_ANALYZER_STAGE_2A.md), [ROADMAP.md](ROADMAP.md) блок R1

## 1. Проблема

### 1.1. Симптом

При автоматической детекции баблов (tiled YOLO, class 1) на одну реплику часто попадает **несколько пересекающихся рамок**, частично не покрывающих бабл. Это брак геометрии: кривой кроп → кривой OCR → лишние правки.

### 1.2. Почему это не лечится «до нуля»

| Фактор | Следствие |
|--------|-----------|
| Manga-YOLO не заточен под все стили комиксов | Осколки bbox, пропуски |
| Tiled inference + NMS | Дубли с низким IoU («две половинки» одного бабла) |
| Любые улучшения det (ogkalu, merge, VLM-refine) | Снижают частоту ошибок, но **не убирают** необходимость проверки |

### 1.3. Скрытая цена auto-first

```
Auto-first:  YOLO → правки рамок → OCR → правки текста → № → save
             (две непредсказуемые волны правок)
```

Пользователь **всё равно** проходит все панели; время на «починку авто» сопоставимо с аккуратной расстановкой рамок вручную, но процесс менее предсказуем и раздражает.

### 1.4. Цель качества

Для построения **истории и хронологии фраз** authoritative источник — **человек** (где бабл, в каком порядке). ML остаётся сильным на **OCR по заданному кропу**, не на «угадать все рамки без ошибок».

---

## 2. Решение (принятое направление)

### 2.1. Концепция manual-first

**По умолчанию** пользователь сам задаёт геометрию; автодетекция — **опциональный assist**, не часть основного пайплайна.

### 2.2. Целевой процесс (ручной режим)

```
1. Открыть панель (навигация ◀ / ▶)
2. Расставить рамки поверх баблов (draw / добавить / править drag-resize)
3. Нажать «Распознать текст» — OCR для всех рамок на текущей панели
4. При необходимости править текст (sidebar / detached frame)
5. Расставить reading_order (№, ↑↓)
6. Сохранить проект → следующая панель
```

**Ожидаемый результат:** ~95%+ качества без возврата к «переделке рамок»; одна осознанная волна работы на панель.

### 2.3. Альтернатива (автоматический режим)

Сохраняется для пользователей, которым нужен быстрый черновик:

```
1. Указать проект + папку панелей
2. «Запустить детекцию + OCR» — batch YOLO + OCR по всем панелям
3. Ручная доводка рамок, текста, порядка (как сейчас)
```

YOLO **не удаляется** из кодовой базы; меняется **дефолт и точка входа в UI**.

## 3. UI: переключатель режимов

### 3.1. Размещение

Секция **«Режим работы»** в sidebar вкладки **ExText** (панель настроек), **над** полями проекта / папки панелей.

### 3.2. Элемент управления

Radio group (взаимоисключающие):

| Значение | ID | Подпись | Default |
|----------|-----|---------|---------|
| `manual` | `s2a-mode-manual` | **Ручной** — рамки вручную, OCR по кнопке | ✅ **checked** |
| `auto` | `s2a-mode-auto` | **Авто** — YOLO + OCR по всей папке | |

Краткая подсказка под radio (`.preset-hint`):

- **Ручной:** «Сначала рамки, затем распознавание текста на панели.»
- **Авто:** «YOLO находит баблы на всех панелях; правки после прогона.»

### 3.3. Смена функциональных кнопок

Один контейнер `#s2a-action-buttons`; при смене radio — перерисовка/переключение видимости кнопок (без перезагрузки страницы).

#### Ручной режим (`manual`)

| Кнопка | ID | Действие |
|--------|-----|----------|
| **▶ Распознать текст на панели** | `s2a-btn-ocr-panel` | OCR всех баблов **текущей** панели (batch re-OCR) |
| **↻ Загрузить проект** | `s2a-btn-load` | Как сейчас |
| **+ Нарисовать бабл** | `s2a-add-mode` | Режим рисования rect на канвасе (см. §4.2) |

Скрыто / неактивно:

- `s2a-btn-run` («Запустить детекцию + OCR» по всей папке)

#### Автоматический режим (`auto`)

| Кнопка | ID | Действие |
|--------|-----|----------|
| **▶ Запустить детекцию + OCR** | `s2a-btn-run` | `POST /api/story/stage_2a/process` (как сейчас) |
| **↻ Загрузить проект** | `s2a-btn-load` | Как сейчас |
| **🔍 Предложить баблы на панели** | `s2a-btn-detect-panel` | YOLO **только текущей** панели, **без OCR** (новый API, см. §5.3) |

Скрыто / переименовано:

- Batch OCR по одной кнопке на панели — опционально оставить «Распознать текст на панели» и в auto (после правок bbox)

### 3.4. Persist

Поле в `ui_state.story2a`:

```json
{
  "project": "…",
  "panels_dir": "…",
  "workflow_mode": "manual"
}
```

- Значения: `"manual"` | `"auto"`
- Default при отсутствии ключа: `"manual"`
- Сохранение: `frontend/ui_state.js` + `utils/ui_state.py` (`default_story2a()`)
- Сброс секции ExText (↺) → `workflow_mode: "manual"`

### 3.5. Папка панелей и сессия

- При смене «Папка панелей» при открытом проекте — `clearSession()` (редактор очищается, toast с подсказкой).
- «Загрузить проект» с указанной папкой: `POST /sync_panels` → `GET /{project}?panels_dir=…`.
- Привязка `boundPanelsDir` фиксирует, с какой папкой открыт проект.

## 4. Поведение по режимам

### 4.1. Общее (оба режима)

Без изменений:

- Навигация по панелям
- Drag / resize bbox, chrome № / ↻ / × на рамке
- Detached text frame (`#s2a-bubble-frame`)
- Sidebar: тип, текст, список баблов, reading_order
- **💾 Сохранить и проверить JSON**
- Re-OCR одного бабла (↻ на chrome)

### 4.2. Ручной режим — детали

#### Инициализация проекта

| Действие | Поведение |
|----------|-----------|
| Новый проект | **«Создать из папки»** → `POST /init` — `stage_2a.json` с пустыми `bubbles: []` на каждой панели |
| Загрузка существующего | **«Загрузить проект»** — sync PNG + `GET /{project}?panels_dir=` |

**Не вызывается** `POST /process` без явного переключения в auto.

#### Рисование рамок

| Способ | Описание |
|--------|----------|
| **Draw rect** | Клик-drag на канвасе (как Split rect) — **новое**, приоритет для manual-first |
| **+ Нарисовать бабл** | Включает режим draw; курсор crosshair |
| Fallback | Текущий «+ Добавить бабл» (~10–40% панели) — оставить как быстрый stub или заменить на draw-only |

Минимальный размер bbox: `min_bubble_area_px` из конфига (32 px).

#### Batch OCR панели

`POST /api/story/stage_2a/{project}/ocr_panel`

Body:

```json
{
  "panel_id": "p003",
  "panel_abs_path": "exam_img/…/003_p003_panel.png"
}
```

- Для каждого бабла на панели с непустым bbox → тот же pipeline, что `reocr`
- Пустой список баблов → toast «Нет рамок для распознавания»
- Progress: `setStatus2a('OCR 2/5…')`, блокировка кнопки на время запроса
- После успеха: обновить sidebar и detached frame

#### Порядок работы (рекомендуемый UX)

1. Рамки → 2. «Распознать текст на панели» → 3. Правки текста → 4. № → 5. Save

### 4.3. Автоматический режим — детали

| Действие | API / поведение |
|----------|-----------------|
| **Запустить детекцию + OCR** | `POST /process` — без изменений семантики |
| **Предложить баблы на панели** | `POST /{project}/detect_panel` — только YOLO, merge в существующие bubbles **или** replace (см. §5.3) |
| После auto-прогона | Пользователь правит как сейчас; snap (блок S roadmap) полезен здесь сильнее |

## 5. API

### 5.1. Существующие (без смены контракта)

| Метод | Путь | Использование |
|-------|------|---------------|
| GET/PUT | `/{project}` | Load / save |
| POST | `/{project}/reocr` | Один бабл |
| POST | `/process` | **Только auto-режим** (batch det + OCR) |

### 5.2. Новые

#### `POST /api/story/stage_2a/{project}/ocr_panel`

OCR всех баблов одной панели.

**Request:**

```json
{
  "panel_id": "p001",
  "panel_abs_path": "optional/absolute/or/relative.png"
}
```

**Response:**

```json
{
  "panel_id": "p001",
  "bubbles_updated": 3,
  "ocr_ms": 6200,
  "document": { … }
}
```

#### `POST /api/story/stage_2a/{project}/detect_panel` (auto assist)

YOLO только на одной панели, без OCR.

**Request:**

```json
{
  "panel_id": "p001",
  "panel_abs_path": "…",
  "merge_mode": "append"
}
```

`merge_mode`:

- `"append"` — добавить новые bbox (dedupe IoU с существующими)
- `"replace"` — заменить bubbles панели результатом YOLO

**Response:** обновлённый `document` + `boxes_added`.

#### `POST /api/story/stage_2a/{project}/init` (опционально, фаза 1.1)

Создать проект из папки панелей **без детекции**: скан PNG → панели с `bubbles: []`.

Если проще — `load` при отсутствии JSON создаёт skeleton на первом save; зафиксировать при реализации.

### 5.3. `POST /process` в manual-first

- Endpoint **остаётся**
- В UI **не вызывается** при `workflow_mode === 'manual'`
- В документации: «batch auto pipeline»

## 8. Критерии приёмки (manual-first)

| # | Критерий |
|---|----------|
| A1 | Default radio = **Ручной**; persist после reload |
| A2 | В ручном режиме нет кнопки batch «YOLO + OCR по папке» |
| A3 | Draw rect + drag/resize; минимум один способ добавить бабл |
| A4 | «Распознать текст на панели» — OCR всех bbox на текущей панели |
| A5 | Auto-режим: «Запустить детекцию + OCR» работает как до изменений |
| A6 | Save/load JSON; reading_order; chrome ↔ sidebar синхрон |
| A7 | На 10 панелях пользователь проходит flow без обязательного возврата к «переделке всех рамок» |
