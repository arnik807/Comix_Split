## Azure из России — честная картина

Основная сложность — не регистрация, а оплата. В 2026 году прямой платёж российской банковской картой часто не проходит из-за ограничений международных платёжных систем.

Microsoft не принимает карты из РФ — даже цифровые коды и альтернативные платежи часто блокируются на этапе проверки.

**Что работает в 2025–2026:**

Схема через виртуальную карту: Telegram-бот → регистрация 2 минуты → пополнение рублями через СБП из любого российского банка → конвертация в доллары за 1–2 минуты → добавить в Azure Portal как payment method → работает. Процесс от регистрации до первого платежа — 5–7 минут.

Есть посредники, которые оплачивают за вас своими иностранными картами с комиссией ~20% (но не менее 300 руб.) от суммы платежа.

**Итого по Azure из РФ:**
- Регистрация — без проблем
- Оплата в рамках **бесплатного тира** — не нужна вообще, Azure просто принимает карту для верификации и снимает $1 на проверку (затем возвращает)
- Платная подписка — через посредника или виртуальную карту, +15–20% к стоимости

## Главный инсайт который оба ответа пропустили

У тебя в проекте **уже есть Qwen2.5-VL через SiliconFlow** — это VLM, который умеет читать текст с изображений. Он используется в Stage 2b для визуальных описаний панелей. Но он же может делать OCR баблов — и делать это качественно, потому что это именно VLM-подход который ты видишь на телефоне.

Никаких новых регистраций, никаких новых API-ключей:

```python
# Тот же провайдер что уже в конфиге
def ocr_bubble_via_vlm(bubble_crop_path: str, provider) -> str:
    """
    OCR бабла через Qwen2.5-VL — тот же API что уже используется в Stage 2b.
    Читает комиксный шрифт как VLM, не как набор букв.
    """
    return provider.vision_chat(
        image_path=bubble_crop_path,
        prompt=(
            "Extract ALL text visible in this comic speech bubble. "
            "Return only the text, nothing else. "
            "Preserve line breaks. Language may be Russian or English."
        )
    )
```
